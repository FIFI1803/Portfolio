Why Ember, not Yellow?
Yellow-on-dark-gray is the default template palette for 80% of dev portfolios right now. Ember (#FF5C2B) is a warm, burnt orange-red — still energetic and bold, but immediately distinctive. It reads as ambitious, creative, and driven. On deep near-black backgrounds it creates a cinematic contrast that feels premium rather than default.

04 — Voice

Brand Voice & Tone

✓ Do
→Confident but not arrogant. Own what you know.
→Show the process, not just the result. People connect with the journey.
→Be specific. "I built X with Y because Z" beats "I'm passionate about tech."
→Honest about what you're still learning. That's the brand.
→Short sentences. Punchy. Leave white space.
✗ Don't
→Generic phrases: "passionate developer", "team player", "hard worker".
→Overclaiming seniority. You're a junior building in public — own that.
→Polished corporate tone. You're a person, not a company.
→Disappearing for weeks then trying to "catch up". Consistency beats intensity.
→Waiting until it's perfect. Ship it. Update it.

06 — Implementation

Next Steps for the Portfolio

1
Replace yellow-400 → Ember (#FF5C2B)
Global find & replace in all component files. One change, instant identity shift.
2
Swap Mona Sans → Syne + DM Sans
Syne for headings/nav/buttons. DM Sans light for body text. Import both from Google Fonts.
3
Deepen backgrounds: gray-950 → #0D0D0F / #13131A
Richer, more moody than Tailwind's default gray. Subtle but noticeable.
4
Add a radial ember glow to the Hero section
A subtle radial-gradient behind the hero text — rgba(255,92,43,0.10). Cinematic atmosphere with one CSS line.
5
Update index.html title + meta description
"portfolio" → "Filip Galach — Software Developer". Add a meta description. Tiny SEO win, makes you look professional.
